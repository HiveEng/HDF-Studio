# PDF/A, accessibility and document checks

## Check document

**Protect › Check document** reviews the file for PDF/A archiving, accessibility and security problems, and lists what it found.

## Save as PDF/A

**Protect › Save as PDF/A** (also on the Convert tab) converts the document to PDF/A-2b for long-term archiving: fonts embedded, no encryption, no external dependencies. Save the result to keep it.

PDF/A conversion uses Ghostscript, a free program. If it isn't installed, {{app}} tells you where to get it.

## Making a PDF accessible

| Command | What it does |
|---|---|
| **Make accessible** | Tags headings, paragraphs, lists, tables and images so screen readers read the document in the right order. Headers, footers and decoration are marked to be skipped. |
| **Describe images** | Lets you write alt text (a short description) for every image. Tag the document first. |
| **Title & language** | Sets the document title, its language and the tab order, which screen readers need. |

[[Ctrl+Z]] undoes each of these.
