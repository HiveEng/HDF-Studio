# Creating and exporting

![The Convert tab](ribbon-convert.png "wide")

## Creating PDFs

**Convert › From files** (or **Create PDF** on Home, [[Ctrl+N]]) makes PDFs from:

- Word, Excel and PowerPoint files (converted with LibreOffice, which must be installed)
- images: PNG, JPEG, TIFF, BMP, GIF
- HTML and plain text

Choose the page size for images and text (keep the original size, or Letter, A4, Legal, A3) and whether to make **one combined PDF** or **one PDF per file**.

You can also drop these files onto the {{app}} window. **Blank PDF** and **Combine files** are here too; see [Opening, saving and printing](#open-save).

## Exporting

**Convert › Export** ([[Ctrl+Shift+E]]) saves the PDF as:

| Format | Notes |
|---|---|
| **Word (.docx)** | Editable text and pictures |
| **Excel (.xlsx)** | Tables and schedules come out as real cells. One sheet per page, or everything on one sheet. |
| **PowerPoint (.pptx)** | One slide per page, with editable text boxes over the page or pictures of the pages only |
| **Images** | PNG, JPEG, TIFF or BMP; see [Saving pages as images](#save-images) |
| **Web page (HTML)** | |
| **Plain text** | |
| **SVG** | One vector file per page |

> **Tip:** Exporting a drawing to Word rarely helps. To use a drawing in AutoCAD, Revit or a report, [save it as images](#save-images) instead, or [extract an area](#extract-image).
