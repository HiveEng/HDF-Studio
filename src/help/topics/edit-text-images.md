# Editing text and images

The **Edit** tool ([[E]]) changes the PDF's own content, not just markups on top of it.

![The Edit tab](ribbon-edit.png "wide")

## Changing text

1. Click **Edit text & images** (Edit tab) or press [[E]].
2. Click the text you want to change. A box opens around the paragraph.
3. Type your changes. The paragraph re-wraps within its column.
4. Click elsewhere to finish. [[Ctrl+Z]] undoes.

Changed paragraphs are rewritten in the nearest standard font (Helvetica, Times or Courier), in the original size and colour where possible.

## Adding new text

With the Edit tool, click on empty space and type. **Text style** (Edit tab) sets the font, size and colour for new text.

> **Note:** For notes and comments that others should see as markup, use a [text box](#text-boxes) instead. Edited text becomes part of the page.

## Pictures

| To | Do this |
|---|---|
| Insert a picture | **Insert image**, pick a file, then click where it goes. |
| Select a picture | Click it with the Edit tool |
| Move it | Drag it |
| Resize it | Drag a corner (hold [[Shift]] to stretch freely) |
| Turn it | Drag the round knob, or press [[[]] and [[]]] to turn 90° |
| Set an exact size and angle | Right-click › **Size and rotation** |
| Replace it | **Replace** (Edit tab), right-click › **Replace image**, or [[Ctrl+R]] |
| Save it as a file | Right-click › **Save image as** |
| Delete it | [[Delete]], or right-click › **Delete image** |

To save a picture or any area of the page without the Edit tool, see [Extracting images](#extract-image).

## Find and replace

To change a word everywhere, use **Find & replace** ([[Ctrl+H]]). See [Find and replace, and spelling](#find-replace-spell).
