# A tour of the window

![The parts of the {{app}} window](window-tour.png "wide")

| # | Part | What it's for |
|---|---|---|
| 1 | **Task tabs** | Home, Comment, Measure, Edit, Organize, Fill & Sign, Protect, Convert and Automate. Each tab holds the tools for one job. {{app}} remembers the last tab you used. |
| 2 | **Undo and Redo** | Always beside the tabs, whichever tab is showing. [[Ctrl+Z]] and [[Ctrl+Y]] do the same. |
| 3 | **Search document** | Finds words in the open PDF. See [Searching a document](#search). |
| 4 | **Tools** | Opens the command search ([[Ctrl+K]]): type part of any command's name and press [[Enter]]. |
| 5 | **Help (?)** | This guide ([[F1]]), keyboard shortcuts, what's new and Check for updates. |
| 6 | **Settings and theme** | The gear opens [Settings](#settings); the moon or sun switches between light and dark. |
| 7 | **Ribbon** | The buttons for the current tab, in labelled groups. On a narrow window the groups shrink to small buttons and then to icons; hover for the name. |
| 8 | **Document tabs** | One tab per open file. A dot means unsaved changes. [[Ctrl+Tab]] moves to the next tab and [[Ctrl+W]] closes one. |
| 9 | **Panel rail** | Shows a panel in the sidebar: Pages, Bookmarks, Search results, Comments, Attached files, Layers and Tool chest. |
| 10 | **Sidebar** | The chosen panel. [[F4]] shows or hides it. See [Sidebar panels](#panels). |
| 11 | **Page view** | The document. Scroll, zoom and mark up here. Right-click for page commands. |
| 12 | **Status bar** | Tells you what just happened and what to do next ("Click the arrow tip…"). Hover over long messages to read them in full. |
| 13 | **Page and zoom bar** | Previous and next page, page number, zoom out, zoom level, zoom in, fit width and fit page. It sits in the middle of the footer on every tab. |

## The start screen

When no document is open, {{app}} shows the start screen: big buttons for the most common jobs and your recent files, including recent Microsoft 365 files.

![The start screen](start.png)

Drop PDF files anywhere on the window to open them. Drop Word, Excel, PowerPoint, image or HTML files to turn them into PDFs.

## The ribbon tabs at a glance

![Home tab](ribbon-home.png "wide")

The **Home** tab gathers what you need most: Open, Save, Print, Save as, Create PDF and OCR; Open from 365 and Save to 365; the most-used tools (Hand, Select, Highlight, Cloud, Measure, Edit, Sign); and view commands. Every tab is described button by button in the [Ribbon reference](#ribbon).

## Light and dark themes

Click the moon or sun at the top right, or choose a theme in **Settings › General**. Dark mode darkens the window around the page; drawings keep their own colours so markups read the same.

## Narrow windows and laptops

{{app}} fits windows as narrow as 1366 pixels without hiding tools. When space runs out the ribbon shows groups as small buttons, then as icons only. Hover over an icon to see its name, or use [[Ctrl+K]].
