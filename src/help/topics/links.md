# Links, bookmarks and attachments

## Links

1. Click **Edit › Link**.
2. Drag a box over the text or area that should be clickable.
3. Choose what it links to: a page in this document, a web address, or an email address.

With the Link tool active, click an existing link to edit it, or right-click it to delete it. Press [[Esc]] when done.

With the Hand tool, clicking a link follows it. After jumping to another page, [[Alt+Left]] takes you back.

## Bookmarks

- **Edit › Bookmark** or [[Ctrl+D]] bookmarks the current view.
- Manage bookmarks in the **Bookmarks** panel: right-click a bookmark to rename ([[F2]]), retarget, add a sub-bookmark, indent, outdent or delete it. See [Sidebar panels](#panels/bookmarks).
- **Combine files** adds a bookmark for each file automatically.

## Attachments

**Edit › Attach file** embeds calculations, specifications, CAD files or photos inside the PDF, so they travel with it. Open the **Attached files** panel to save or remove them.

## Layers

**Edit › Layers** opens the Layers panel, where you can show or hide CAD layers. See [Sidebar panels](#panels/layers).
