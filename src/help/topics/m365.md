# Opening and saving with Microsoft 365

{{app}} opens and saves files in your Microsoft 365 storage directly, without the OneDrive sync app. It uses the same work account you signed in with.

## Opening a file

1. Click **Home › Open from 365**, the **Open from 365** card on the start screen, or press [[Ctrl+Alt+O]].
2. Choose a place on the left: **OneDrive** (your own files and folders), **Recent** (files you used lately, wherever they live) or **Shared with me** (files and folders colleagues shared with you).
3. Open folders with a double-click, go back with the path at the top, select a PDF and click **Open**.

![The Microsoft 365 file window](m365-open.png "small")

The status bar says where the file came from, and the file joins your recent files on the start screen with a cloud icon.

## Saving

- A file opened from 365 saves back to the same place with **Save** ([[Ctrl+S]]).
- **Save to 365** ([[Ctrl+Alt+S]]) saves any open file to a folder in your OneDrive. Type a name and click **Save**. If a file with that name exists, {{app}} asks before replacing it.

If someone else changed the file since you opened it, {{app}} asks what to do: **save your version as a copy next to it** (the safe choice), or **replace their changes with yours**.

To open the file's OneDrive page in your browser (for sharing or version history), press [[Ctrl+K]] and choose *Show this file in OneDrive/SharePoint*.

> **Note:** {{app}} browses OneDrive, Recent and Shared with me. To open a file from a SharePoint site or Team that isn't in those lists, open it once in the browser (it then appears in **Recent**), or use the synced folder in File Explorer.

## If it doesn't connect

- Make sure you're signed in to {{app}} with your work account and connected to the internet.
- The first time, Microsoft may ask you to allow {{app}} to read and write your files. If it says an administrator must approve, ask IT.
