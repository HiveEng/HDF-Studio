# Opening, saving and printing

## Opening files

- Click **Open** on the Home tab, or press [[Ctrl+O]]. You can pick several files at once; each opens in its own tab.
- Drag PDF files from File Explorer onto the {{app}} window.
- Double-click a PDF in File Explorer if {{app}} is your PDF app (the installer offers this), or right-click it and choose **Open with › {{app}}**.
- Click a file under **Recent** on the start screen. Recent files from OneDrive show a cloud icon.
- To open from OneDrive, see [Microsoft 365](#m365).

Password-protected PDFs ask for their password when they open.

> **Note:** Dropping a Word, Excel, PowerPoint, image, HTML or text file onto the window turns it into a PDF. See [Creating and exporting](#convert).

## Working with several files

Each file has a tab under the ribbon. Click a tab to switch, or press [[Ctrl+Tab]] and [[Ctrl+Shift+Tab]]. [[Ctrl+W]] closes the current tab. A dot on a tab means it has unsaved changes.

## Saving

| To | Do this |
|---|---|
| Save changes to the same file | **Save** or [[Ctrl+S]] |
| Save a copy under a new name or folder | **Save as** or [[Ctrl+Shift+S]] |
| Save to OneDrive | **Save to 365** or [[Ctrl+Alt+S]] (see [Microsoft 365](#m365)) |

A file opened from OneDrive saves back to OneDrive with [[Ctrl+S]].

If you close {{app}} with unsaved changes, it asks before closing so nothing is lost.

> **Important:** Some changes are made permanent only when you save, such as applied redactions and password protection. Until you save, [[Ctrl+Z]] can still undo them.

## Undo and redo

Almost everything can be undone: markups, page changes, edits, OCR, flattening and redaction (until you save). Use the arrows beside the ribbon tabs, or [[Ctrl+Z]] and [[Ctrl+Y]].

## Printing

Click **Print** or press [[Ctrl+P]].

![The Print dialog](print.png "small")

- **Pages:** all pages, the current page, the pages selected in the Pages panel, or a range such as `1-3, 7, 10-`, `odd` or `even`.
- **Size:** *Actual size* prints each page at its true size, so a drawing prints to scale on paper that matches (for example 11x17 or ARCH D). *Fit to paper* shrinks or enlarges pages to fit.
- **Include:** the document and its markups, or the document only (no comments or form fields).
- **Quality:** Draft (150 dpi, faster), Standard (300 dpi) or High (600 dpi, for fine drawing detail).
- After you click Print, Windows asks for the printer, paper, copies and colour.

Your usual print size and quality are kept in **Settings › General**.

> **Tip:** For a scale plot, check the sheet's scale bar after printing. Printing at *Fit to paper* changes the scale.

## Creating new PDFs

| Command | What it makes |
|---|---|
| **Create PDF** ([[Ctrl+N]]) | A PDF from Word, Excel, PowerPoint, images, HTML or text files. Several files can become one PDF or one each. |
| **Blank PDF** ([[Ctrl+Shift+N]]) | Empty pages in Letter, A4, Legal, A3 or A5, portrait or landscape. |
| **Combine files** ([[Ctrl+Shift+M]]) | One PDF from several, with a bookmark for each file. See [Organizing pages](#organize). |

Office files are converted with LibreOffice when it's installed on the computer.
