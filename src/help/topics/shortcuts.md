# Keyboard and mouse shortcuts

Shortcuts use Windows keys. Single-letter tool keys work when the page has focus, not while you're typing in a box.

## Mouse and drawing

| Action | How |
|---|---|
| Pan | Middle mouse button and drag, or hold [[Space]] and drag |
| Zoom | [[Ctrl]] + mouse wheel |
| Scroll sideways | [[Shift]] + mouse wheel |
| Select markups inside a box | Hand tool: drag left to right on empty space |
| Select markups the box touches | Hand tool: drag right to left on empty space |
| Add or remove one markup from the selection | [[Shift]]+click or [[Ctrl]]+click |
| Select every markup on the page | [[Ctrl+A]] (Hand tool) |
| Delete selected markups | [[Delete]] |
| Edit a selected markup's text | [[Enter]], or double-click a text box or callout |
| Context menu | Right-click the page, a markup, a thumbnail, a bookmark or an attachment |
| Finish a cloud, polyline, polygon, area or polylength | Right-click, double-click or [[Enter]] |
| Remove the last point while drawing | [[Backspace]] |
| Straight line (0°, 45°, 90°) | Hold [[Shift]] while drawing |
| Place a point without snapping | Hold [[Alt]] |
| Finish typing a text box or callout | [[Ctrl+Enter]] or click elsewhere |
| Turn a text box in 15° steps | Hold [[Shift]] while dragging the round knob |
| Resize a picture or stamp freely | Hold [[Shift]] while dragging a corner |
| Turn a selected picture, stamp or signature 90° | [[[]] and [[]]] |
| Cancel the current tool or drawing | [[Esc]] |
| Back after following a link | [[Alt+Left]] |
| Next form field | [[Tab]] |
