# Tool chest and saved styles

The **tool chest** holds ready-to-use markup tools, each with its own colour, line width and text size: a red revision cloud, a blue length, an *Approved as Noted* stamp and so on. Click one and start marking up.

Open it with the toolbox icon on the panel rail, or **Comment › Tool chest**.

![The tool chest panel](tool-chest.png "small")

## Using a saved tool

Click a tool in the chest. It becomes the current tool with its saved settings. Pick another tool, or press [[Esc]], to go back to your normal settings.

The chest starts with: red revision cloud, red callout, see-through yellow highlight box, *Approved as Noted* and *Revise and Resubmit* stamps, blue length, green area and red count dots.

## Saving your own

- Set up a tool the way you like, then click **Save tool** (Comment tab) or **+ Save tool** in the chest, and give it a name.
- Or right-click a text box or callout, choose **Style**, and under **Use this style** pick *For this one, and save it to the tool chest*.

Right-click a tool in the chest to **Use** it, **Edit** its name and settings, **Move up**, **Move down** or **Remove** it.

## Sharing the chest with your team

1. Click **Export** in the chest and save the file (for example on a shared drive or Teams).
2. Colleagues click **Import**, pick the file, and choose to add the tools to their chest or replace it.

Now everyone's clouds, callouts and stamps look the same.

## Default styles

Separate from the chest, each kind of tool has a default style that every new markup starts with. Change defaults in **Settings › Tools**, or from a text box or callout's **Style** dialog with *For this one and every new …*. See [Settings](#settings).
